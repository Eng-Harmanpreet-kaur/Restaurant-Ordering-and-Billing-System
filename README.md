# 🍽️ Restaurant Management System in C++

## 📌 About the Project

The Restaurant Management System is a console-based C++ project developed to manage restaurant orders and billing. It allows customers to select food items, calculate their bills, and save bill records. It also provides a staff panel to view saved bills and pending orders.

This project is developed using **C++ and Data Structures** to understand how programming concepts are used in a real-life application.

## ✨ Features

* **Customer Panel:** Select food items and place orders.
* **Food Menu:** Choose from different food categories.
* **Automatic Billing:** Calculate the total amount based on item prices and quantities.
* **Order Management:** Add and remove orders.
* **Stack:** Manage recent order operations.
* **Queue:** Maintain pending food items.
* **Linked List:** Store and manage order details.
* **File Handling:** Save bills in a file and view previously saved bills.
* **Staff Panel:** Access saved bills and pending orders.
* **Input Validation:** Handle invalid menu choices.
